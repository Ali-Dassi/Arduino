# 🔌 Arduino Mini Projects – Beginner to Intermediate

Welcome to my **Arduino Mini Projects Repository**!

This repository contains a collection of 6 practical Arduino projects developed as part of my learning journey in electronics and embedded systems.

The main goal is to learn Arduino programming, understand electronic components, and gradually build interactive systems through practical experimentation.

Each project introduces new components, concepts, and programming techniques.

---

## 🎯 Learning Path

The projects are organized in a progressive way, starting with simple input/output control and moving towards more interactive systems.

### 🟢 Project 1 – Ultrasonic Sensor with Buzzer and LEDs
**Folder:** `Projet1_ultrasonic buzzer with lights`

**Idea:**
A distance detection system using an ultrasonic sensor.

**How it works:**
- The ultrasonic sensor measures the distance to an object.
- LEDs indicate the distance level.
- A buzzer provides an audible warning when an object gets closer.

**What I learned:**
- Ultrasonic sensor basics
- Distance measurement
- Digital outputs
- Buzzer and LED control

---
